# 🌿 Greenden - Plant Website

Greenden is a responsive plant website created using **HTML and Tailwind CSS**.  
The website is designed for users who are interested in natural and artificial plants for their homes and interiors.

## 🌱 About the Project

Greenden provides a simple and clean interface for exploring different plants, learning about the services offered, and contacting the business.

This project was created to practice and improve my skills in **Tailwind CSS**, responsive web design, layouts, forms, and multi-page website development.

## ✨ Features

- 🏠 **Home Page**
  - Responsive navigation bar
  - Hero section
  - Introduction to the website
  - About Us section
  - Services/features section
  - Best-selling plants
  - Customer reviews
  - Newsletter subscription section
  - Footer

- 🌿 **Products Page**
  - Product listing
  - Plant images
  - Product names and prices
  - Responsive product grid
  - Hover effects on products

- 📩 **Contact Page**
  - Contact Us section
  - Email input
  - Subject input
  - Message textarea
  - Submit button
  - Responsive form layout

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- CSS Grid
- Flexbox
- Responsive Design

## 📱 Responsive Design

The website is designed to work across different screen sizes:

- 📱 Mobile
- 💻 Tablet
- 🖥️ Desktop

Tailwind CSS responsive utilities such as `sm:`, `md:`, and `lg:` are used to create responsive layouts.

## 🎨 Tailwind CSS

This project was built using Tailwind CSS utility classes instead of writing traditional CSS for the main website styling.

Some Tailwind CSS utilities used in the project include:

- `flex`
- `grid`
- `grid-cols-2`
- `md:grid-cols-4`
- `p-4`
- `m-4`
- `text-center`
- `font-bold`
- `bg-green-100`
- `rounded`
- `shadow-xl`
- `hover:shadow-xl`
- `md:hidden`
- `md:flex`
